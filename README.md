# NIGRAANI

“Speak the site. Prove the work. Protect public money.”

NIGRAANI is a voice-verified field-inspection command center for public infrastructure projects. An inspector walks the site, speaks their observations naturally (in English, Hindi, or Hinglish), and NIGRAANI extracts structural facts, compares them to the baseline plan, and stages safe escalations based on the Truth Gap.

## Architecture
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4, shadcn/ui, Aceternity (Framer Motion)
- **Voice Agent**: AssemblyAI Realtime API via WebSockets
- **State**: Local mock data (for hackathon deterministic demos)

## Setup
1. Clone the repo.
2. Run `npm install`
3. Copy `.env.example` to `.env.local`
4. Optional: Add your `ASSEMBLYAI_API_KEY` for live voice testing.
5. Run `npm run dev`

## Demo Script
1. Start at `/` to view the landing page.
2. Click **Start Field Demo** to enter `/inspection` (or `/demo` to pick a scenario).
3. The dashboard shows the Project Context on the left.
4. Click **Start Site Walk** in the center panel.
5. Read the observation aloud or simulate transcript events.
6. The Truth Gap Engine (Right panel) will automatically recompute discrepancies and stage an escalation.
7. Confirm the read-back and view the generated `/report` for the supervisor.

## Security Notes
- `ASSEMBLYAI_API_KEY` must never be exposed to the client. We use an ephemeral token generated by `/api/session`.
- The Voice Agent only suggests actions; all reports require explicit user confirmation to submit.
- The UI contains explicit "DEMO DATA" warnings, as this is a mock interface.
